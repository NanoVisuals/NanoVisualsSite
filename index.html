FAQ — возможные ошибки

Здесь собраны все типовые проблемы с установкой файлов игры, Java и запуском лаунчера. Ищи свою ошибку в поиске или по списку ниже.

Неправильно установились файлы игры

Симптомы: игра падает при запуске, в логе ошибка вида Missing model, блоки без текстур, чёрный экран, мир не грузится.

  1. Открой лаунчер → вкладка Файлы игры → нажми Проверить и восстановить. Лаунчер сам скачает недостающие файлы.
  2. Если папка игры повреждена целиком — переустанови Minecraft через официальный лаунчер (или через лаунчер → Установить игру).
  3. Проверь, что у игры хватает места на диске (минимум 4 ГБ) и что путь не содержит кириллицу и спецсимволы.
  4. Удали папку versions/<версия>/ и запусти установку заново — файлы пересоздадутся.

⚠️ Не редактируй файлы игры вручную, пока открыт лаунчер — он перезапишет изменения.

Неправильно указан путь к Java

Симптомы: ошибка JAVA_HOME is not set, Invalid Java path, лаунчер не находит Java, кнопка «Запустить» неактивна.

  1. В лаунчере открой Настройки → Java.
  2. Нажми Автоопределить — лаунчер просканирует систему и поставит правильный путь сам.
  3. Если автоопределение не сработало, укажи папку вручную. Это должна быть папка внутри jdk, а не сама папка java.
    Правильно: C:\Program Files\Java\jdk-21.0.5
    Неправильно: C:\Program Files\Java\jdk-21.0.5\bin
  4. Проверь, что по этому пути реально лежит файл bin\java.exe.
  5. Нажми Проверить — должна появиться строка вида Java 21 — OK.

💡 Путь без кавычек и без кириллицы. Не указывай javaw.exe и не компиляторы (IntelliJ IDEA, Eclipse).

Установлена не та Java / несовместимая версия

Симптомы: UnsupportedClassVersionError, ClassNotFoundException, wrong Java version, игра вылетает сразу при старте.

Версия игрыНужная Java
1.21.11 (Fabric)Java 21
  1. В Настройки → Java выбери Java 21 из списка и нажми Применить.
  2. Если Java 21 нет — нажми Скачать Java прямо в лаунчере, всё автоматически.
  3. Удали старые версии Java из «Программы и компоненты» Windows — лаунчеру нужна только Java 21.
  4. В настройках лаунчера проверь «Версия Java по умолчанию для лаунчера» — поставь Java 21.

💡 Для NanoVisuals нужна именно Java 21 — другие версии не подойдут.

Java не скачалась / загрузка прервалась

Симптомы: прогресс зависает на 0%, ошибка Download failed, файл java.zip весит 0 КБ, папка jdk создалась, но внутри пусто.

  1. Закрой лаунчер, удали недокачанный файл из папки ./runtime/ и запусти скачивание заново.
  2. Отключи VPN/прокси или смени сеть — некоторые провайдеры режут соединение с CDN.
  3. Проверь антивирус: он мог заблокировать или удалить файл. Добавь папку лаунчера в исключения.
  4. Скачай Java вручную с Adoptium (Temurin 21) и укажи путь вручную в настройках.
  5. Освободи минимум 500 МБ на диске, где лежит лаунчер.

💡 Не качай Java со сомнительных сайтов — нужен именно Temurin/Oracle JDK, а не JRE и не «JavaFX».

Мод не устанавливается / ошибка при установке

Симптомы: «Не удалось установить мод», конфликт модов, мод не появился в игре.

  1. Убедись, что игра запускается на Fabric 1.21.11 — NanoVisuals работает только с ним.
  2. В лаунчере открой Моды и проверь, что выбран Fabric 1.21.11.
  3. Проверь список несовместимых модов — в логе будет строка Incompatible mod set с названиями.
  4. Удали мод-конфликт из папки mods вручную и попробуй снова.
  5. Если не помогло, перейдите на вкладку Help.
Лаунчер не запускается / вылетает при открытии

Симптомы: окно открылось и сразу закрылось, ошибка JVM, белый экран, cannot find launcher.jar.

  1. Скачай свежую версию лаунчера и запусти от имени администратора.
  2. Проверь, что стоит Java 21 — другие версии лаунчер не поддерживает.
  3. Добавь папку лаунчера в исключения антивируса и «Защищённого просмотра» Windows.
  4. Проверь свободное место: нужно минимум 1 ГБ под кеш и логи.
  5. Удали файл launcher.log в папке лаунчера и запусти снова — он пересоздастся.
  6. Если не помогло, перейдите на вкладку Help.
