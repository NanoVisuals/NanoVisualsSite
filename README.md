# NanoVisuals — сайт

Статический сайт (HTML + CSS + JS) без сборки и зависимостей.
Три раздела: **Home**, **FAQ**, **Help** — переключаются без перезагрузки страницы.

## Как открыть

Просто открой `index.html` двойным кликом.
Если нужно проверить всё как на хостинге — можно залить папку на GitHub Pages / Netlify / Vercel
(либо локально: `python -m http.server 8000` и открыть `http://localhost:8000`).

## Файлы

```
index.html   — разметка и весь текст (Home / FAQ / Help)
styles.css   — оформление, адаптив, анимации
script.js    — переключение вкладок, поиск и фильтр по FAQ, копирование ника
```

### Discord

Сейчас кнопка ведёт на `https://discord.com/app`, а ник `kirill09431` можно скопировать
кнопкой рядом. Discord не умеет открывать личный чат по нику — только по числовому ID.

Если захочешь прямую ссылку в чат, замени `href` в карточке Discord на:

```
https://discord.com/users/ВАШ_ID
```

ID можно скопировать в Discord: настройки → Дополнительно → Режим разработчика,
затем правый клик по своему нику → «Копировать ID».

## Как добавить ошибку в FAQ

Скопируй любой блок и поменяй текст:

```html
<details class="faq" data-cat="java" data-tags="ключевые слова для поиска">
  <summary>
    <span class="faq-ic java"><svg ...></svg></span>
    <span class="faq-q">Текст вопроса</span>
    <span class="faq-arrow"><svg ...></svg></span>
  </summary>
  <div class="faq-a">
    <p>Ответ…</p>
  </div>
</details>
```

`data-cat` — категория для фильтра: `files`, `java`, `launch`, `install` или `all`.
`data-tags` — дополнительные слова, по которым ошибка находится через поиск.
